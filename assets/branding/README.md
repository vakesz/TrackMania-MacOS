# TrackMania Mac hub icon

`trackmania-mac-icon.svg` is the editable source for the native hub icon.
It is an original abstract racing-route mark: it does not reuse a TrackMania,
Nadeo, Ubisoft, or game-executable logo. The app packager rasterizes this
source into the standard macOS Retina icon sizes and compiles `AppIcon.icns`
inside the generated `.app` bundle.
